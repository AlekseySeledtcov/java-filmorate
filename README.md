# java-filmorate
Filmorate — это веб‑сервис на базе Spring Boot для управления коллекцией фильмов и взаимодействия пользователей: оценки кино, обмена рекомендациями и построения социальных связей на основе общих интересов.
_________________

## Описание
- Цель проекта

Создать удобную платформу, где пользователи могут:

хранить информацию о любимых фильмах;

оценивать кино и формировать личный рейтинг;

находить друзей по схожим вкусам;

получать рекомендации на основе лайков и дружеских связей.

- Целевая аудитория

Любители кино, желающие систематизировать свои просмотры.

Сообщества и клубы по интересам для обсуждения фильмов.

Пользователи, ищущие персонализированные рекомендации.

- Контекст разработки

Проект создаётся как учебно‑практический в рамках спринтовой разработки:

Каждый этап реализуется в отдельной ветке Git с последующим Pull Request и автоматизированной проверкой (GitHub Actions).

Архитектура эволюционирует от in‑memory хранения к работе с базой данных (H2).

Активно применяются принципы SOLID и REST‑подход.

- Уникальность

Комбинация функционала киноагрегатора и социальной сети.

Поэтапное наращивание сложности (от каркаса к полноценному API).

Фокус на чистоту кода, тестируемость и расширяемость (интерфейсы для хранилищ, сервисы, DAO).

## Технологии и инструменты

- **Язык:** Java 17.
- **Сборка:** Maven.
- **Фреймворки:** Spring Boot, Spring Web, Spring Data JPA, JUnit.
- **БД:** H2.
- **Прочее:** Spring JDBC, Spring Validation,  Lombok, Jakarta Validation API, REST API, Postman, SLF4J.

## Установка и запуск

### Требования
- Java 17+.
- Maven 3.x.
- Git.
- H2 Database.

### Шаги по установке

#### 1. Клонирование репозитория

1. Откройте терминал/командную строку.

2. Перейдите в папку, где хотите разместить проект.

3. Выполните команду:
```bash
git clone https://ваш-url-репозитория.git
```
   
4. Перейдите в директорию проекта:

```bash
cd filmorate
```

#### 2. Сборка проекта 

1. Вкорневой папке проекта выполните:
```bash
mvn clean package
```

2. ПРоверьте наличие jar файла:
```bash
target/filmorate-0.0.1-SNAPSHOT.jar
```
#### 3. Запуск приложения

1. Запустите приложение командой:
```bash
java -jar target/filmorate-0.0.1-SNAPSHOT.jar
```

2. Приложение стартует на порту 8080 (по умолчанию). Проверьте в браузере:
```http
http://localhost:8080
```
